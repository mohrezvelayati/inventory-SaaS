# Portfolio Demo Checklist

Use synthetic names and phone numbers only.

1. Register an owner and create a store.
2. Create a category and product, then add a size and initial purchase stock.
3. Create a customer and a draft sale; add an item and complete checkout.
4. Confirm stock decreased and the movement history contains the sale entry.
5. Open dashboard and reports and verify revenue, profit, and product metrics.
6. Record an unavailable product request and confirm wanted demand increments.
7. Create a seller invitation, open it in a private session, register the
   employee, and verify capability-aware navigation.
8. Log out and confirm the old refresh token cannot be reused.
9. Once SMS is enabled, complete the password reset workflow and confirm the
   previous password and tokens are rejected.
10. Check readiness, Render logs, Sentry, and the deployed backend/frontend SHAs.

After the demonstration, delete draft-only test records through supported UI/API
operations. Preserve completed sales as audit records; never delete them directly.
